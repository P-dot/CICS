# BMS — MAPSET, MAP and FIELD

The BMS source defines three levels:

```text
L01MAPS     MAPSET
  |
  +-- L01MAP    MAP
        |
        +-- DFHMDF fields
```

`DFHMSD` defines the mapset, `DFHMDI` defines the map, and `DFHMDF` defines screen fields.

The `USERNM` field is unprotected and receives the initial cursor (`ATTRB=(UNPROT,IC)`). The other displayed fields are protected presentation fields.

The BMS build creates two complementary artifacts:

- Physical map: loadable CICS representation used to display the 3270 map.
- Symbolic map: COBOL data definitions generated by the DSECT build and included with `COPY L01MAPS`.
