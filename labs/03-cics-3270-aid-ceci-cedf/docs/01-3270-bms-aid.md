# 3270, BMS and AID

The existing CH01 map was reused. `TEST` was entered in the user-name input field, demonstrating that the field is editable (`UNPROT`) and that the initial cursor is positioned there (`IC`).

Normal character keys alter the terminal field. ENTER produces the attention interaction. The current Lab 01 program sends the map and returns; it does not implement a receive/process cycle for the entered value. The resulting `DFHAC2001` for `TEST` is therefore retained as useful runtime evidence rather than hidden.
